# Stickers — Yier & Bubu (一二布布)

Thả file GIF vào đây theo cấu trúc:

```
Assets/Stickers/
  love/love-01.gif ... love-06.gif
  miss/miss-01.gif ...
  hug/
  kiss/
  tease/
  angry/
  sad/
  cheer/
  goodnight/
  sorry/
  funny/
  hungry/
  jealous/
```

- Tên thư mục = `type` mà app điện thoại gửi (không phân biệt hoa thường).
- Mỗi cảm xúc 4–6 biến thể là đẹp nhất; app tự chọn ngẫu nhiên chống trùng 2 cái vừa hiện.
- Chuẩn file: **GIF động nền trong suốt thật** (không khung trắng), 240–498px, < 500KB/file.
- App preload + decode toàn bộ lúc khởi động → thêm/xoá file cần restart app.
- Type lạ không có thư mục → app lấy bừa 1 GIF bất kỳ (không hiện trống).

> Lưu ý bản quyền: nhân vật của hoạ sĩ Huang Xiao B — dùng cá nhân 2 người thì ổn,
> public/đăng store thì phải thay bằng sticker tự vẽ hoặc có giấy phép.
